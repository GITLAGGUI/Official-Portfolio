# Interface polish

Inspect the actual interface, its content and the user's reference before changing the design. Reuse the existing stack and tokens. Describe the concrete problem the change solves.

- Establish one clear focal point. Use real project media and concise labels; remove repeated destinations and decorative copy that competes with the work.
- Keep content in normal flow. Check the combined height of headings, actions and media before constraining a section. Reserve space for floating graphics and scroll motion.
- Use authentic brand marks for named tools. Treat a category symbol as a category symbol, not a replacement product logo.
- Design hover, keyboard focus and touch together. Hidden descriptions need a visible way to open and dismiss them; Escape should work when they cover meaningful content.
- Animate transform and opacity where possible. Respect reduced motion and provide a persistent pause for continuous movement.

Inspect the rendered result at the intended desktop and a compact phone width. Verify focus, readable text, working actions, image loading and horizontal overflow. Deliver the editable implementation and screenshots of the final state. Report any flow that remains untested.
